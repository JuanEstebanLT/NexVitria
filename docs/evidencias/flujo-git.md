# Evidencia de flujo de trabajo Git y GitHub — NexVitria

## Propósito

Este archivo fue creado como evidencia académica para demostrar el flujo de trabajo utilizado durante el desarrollo de NexVitria.

Los cambios del proyecto no se realizan directamente sobre la rama `main`.

## Flujo utilizado

```text
Issue
  ↓
Rama de trabajo
  ↓
Cambios
  ↓
Validación
  ↓
Commit
  ↓
Push
  ↓
Pull Request
  ↓
Revisión
  ↓
Squash Merge
  ↓
main
```
